# Changelog

All notable changes to VibeSpec are documented here. This project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-16

### Added

- Deterministic, offline generation of complete project specification bundles.
- Commands to initialize a sample idea, generate a bundle, validate its integrity, and export coding-agent instructions.
- Transparent rule-based classification, assumptions, stack recommendations, architecture, security guidance, tasks, and acceptance criteria.
- Safe UTF-8 and cross-platform path handling with explicit overwrite protection.
- Machine-readable manifest with content hashes and tamper detection.
- Example inputs for a booking application and a developer tool.
- Automated tests and CI support for Python 3.11, 3.12, and 3.13.
- Project governance, contribution, security, and release documentation.
